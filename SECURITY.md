# Sécurité

## Signaler une faille

Ne l'écris pas dans une issue publique. Passe par le signalement privé de GitHub :
onglet **Security** du dépôt, puis **Report a vulnerability**. Le message n'est lu
que par l'auteur.

Dis ce que tu as observé, comment le reproduire, et la version concernée
(elle est affichée dans l'appli).

## Ce qui est couvert

La dernière version publiée. Les versions plus anciennes ne reçoivent pas de
correctif : la réponse à une faille est une nouvelle version.

## Ce que tu peux attendre

Aria {{NOM}} est un projet personnel, sans audit de sécurité indépendant. Aucun
délai n'est promis. Une faille confirmée est corrigée dans une nouvelle version,
et les notes de cette version le disent.
